# 🍰 DessertRecycleView

Aplikasi Android sederhana yang dikembangkan untuk mempraktikkan implementasi **RecyclerView**, **Adapter**, dan **CardView** dalam pemrograman aplikasi bergerak menggunakan Kotlin.

---

## 📱 Fitur & Tampilan Aplikasi
- **Dynamic List**: Menampilkan daftar menu *dessert* secara efisien menggunakan komponen `RecyclerView`[cite: 10].
- **Custom Card Layout**: Setiap item dirancang menggunakan tata letak `card_view_design.xml`[cite: 10] untuk menampilkan daftar menu dengan rapi dan interaktif.

---

## 🛠️ Teknologi & Tools yang Digunakan
- **Bahasa Pemrograman**: Kotlin
- **Environment**: Android Studio
- **Komponen Utama**:
  - `RecyclerView`
  - `ConstraintLayout`
  - `CardView`

---

## 📂 Struktur Package & File Utama
- **`MainActivity.kt`**: Activity utama tempat inisialisasi *layout* dan pengelolaan data *RecyclerView*.
- **`activity_main.xml`**: Berkas layout utama yang memuat komponen `RecyclerView`[cite: 10].
- **`card_view_design.xml`**: Berkas layout untuk mendesain tampilan kartu per item di dalam daftar[cite: 10].
